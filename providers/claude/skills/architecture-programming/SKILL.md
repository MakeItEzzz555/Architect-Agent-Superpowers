# Architecture Programming

Use client briefs, project context, schedules, and authoritative requirements.

Produce a provenance-aware requirements matrix; room/space schedule with IDs, quantities and areas; Must/Prefer/Avoid adjacencies; grossing assumptions separate from net area; and open conflicts/questions.

Never invent mandatory requirements or silently mix net, usable, gross internal, gross floor, site, or plot area. State units and area basis. Keep calculations reproducible and expose source conflicts instead of choosing without authority.

Verify totals, duplicates, omissions, impossible targets, conflicting adjacencies, and inconsistent units.
