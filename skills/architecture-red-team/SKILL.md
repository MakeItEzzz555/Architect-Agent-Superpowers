# Architecture Red Team

Review as an independent reviewer. Challenge unverified facts, hidden assumptions, brief/model/drawing/schedule conflicts, likely stakeholder questions, downstream consequences, dimensional/area/count inconsistencies, unsupported compliance claims, irreversible operations, and information that only works with verbal explanation.

Return only high-value findings:
`Risk | evidence | consequence | confidence | required action/owner`

Do not manufacture issues. If something cannot be verified, say so.
