# Architect Agent Superpowers

This extension provides architecture/AEC specialist skills and optional subagents.

Use the smallest relevant specialist capability. Use `architecture-orchestrator` for ambiguous or multi-discipline work. Keep verified facts, project assumptions, design options, and unresolved questions distinct.

Never fabricate site facts, dimensions, regulations, engineering conclusions, costs, or consultant information. Regulated and construction-critical conclusions require competent human review.

Preserve source drawings/models and prefer reversible outputs or dry runs before bulk modifications.
