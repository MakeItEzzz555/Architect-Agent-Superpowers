# Research Basis

This project is maintained against primary vendor/standards documentation and public AEC agent implementations.

## Professional workflow coverage

- RIBA Plan of Work: lifecycle coverage from strategic definition through use.
- AIA architecture basic services: programming, schematic design, design development, construction documents and construction-phase services.
- buildingSMART: IFC/openBIM interoperability, BCF issue exchange, IDS information requirements and bSDD terminology.

These sources inform capability coverage. They do not replace the actual project contract, jurisdiction or appointed consultants.

## Agent / automation lessons incorporated

- Revit and Grasshopper skill packs: version-sensitive knowledge belongs in focused skills; vendor documentation remains live truth.
- Bonsai/IfcOpenShell agent skills: agents can author structured BIM plus plans/sections/elevations, not only discuss design.
- Revit/Rhino/AutoCAD/Archicad/Vectorworks/SketchUp MCP projects: live model operations need explicit write boundaries, tool discovery, screenshots/readback and undo/transaction safety.
- Architecture skill collections: progressive disclosure beats a giant system prompt; safety-critical skills should outrank visual polish.

## Repository-design lesson

TuckBit, Claude Widget Kit and Codex Widget Kit informed the onboarding style: a clear hero/value proposition, copyable agent-install prompt, exact verification, honest capability boundaries, native-provider paths and evidence-driven validation.
