# AEC Lifecycle Coverage

Gridline uses project lifecycle frameworks as **coverage maps**, not universal contracts.

## Coverage map

| Project activity | Primary skills |
|---|---|
| Strategy / briefing | architecture-programming, site-analysis-feasibility |
| Site / feasibility / approvals research | site-analysis-feasibility, site-regulation-research, precedent-research |
| Concept / schematic design | concept-schematic-design, architectural-drawing-generation, concept-design-review |
| Spatial / multidisciplinary coordination | structural-coordination, mep-coordination, civil-site-design, life-safety-accessibility |
| Technical design | construction-documentation, building-envelope-performance, materials-specifications, openbim-ifc-coordination |
| Authoring / automation | revit-workflow, rhino-grasshopper-workflow, autocad-dwg-workflow, cad-bim-automation |
| Performance / cost | sustainability-daylight-energy, area-quantity-audit, cost-planning-value-engineering |
| Tender / construction | construction-documentation, construction-administration |
| Handover / use | handover-fm-postoccupancy |
| Communication | visualization-rendering, presentation-review |
| Independent challenge | drawing-qa, architecture-red-team |

RIBA Plan of Work and AIA basic-services phases informed this coverage map. Project contracts, statutory duties and professional appointments always take precedence.
